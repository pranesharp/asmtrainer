# ASMTRAN

The COA-8 assembly simulator (21CSS201T Computer Organization & Architecture),
a single self-contained `index.html`. 
— assembler, machine, examples, practice checker and reference all run in the browser.

## Assembly Lab - ASM Trainer
An interactive, browser-based simulator for learning Assembly Language and Computer Organization & Architecture.

```Features
Step-by-Step Execution: See your code come to life with real-time visualization of registers, memory, and flags.
Learn by Doing: Ten interactive examples, from basic Load/Store to complex shift-and-add multiplication.
Practice Mode: Test your skills with practice problems and an in-browser checker.
```
## Live at

https://asmtran.pages.dev/

## Run
Just run index.html..

Alternatively from the CLI: `npx wrangler pages deploy . --project-name=assemblylab`.
